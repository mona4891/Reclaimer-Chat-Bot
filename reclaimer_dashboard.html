🗺️ Map & Mode

Set Map, Set Mode and Load Map + Mode end the current game and start the new one in the next lobby. Set Next Game queues a game without ending this one; leave the mode empty to keep the current rules. Click a name to fill the box, or type your own. The server replies when a change is queued; if it can't be completed, the failure shows up under Activity.

⏱️ Round & Game

End Round ends the round as if its time ran out; the leader wins it (needs a round in progress). End Game ends the game with the scores as they stand and reports results as usual.

👥 Teams

Needs a live team round with enough players. Shuffle queues a balanced shuffle among occupied teams.

A team's last player can't be moved during a round.

🗳️ Votes

Starts a vote for the players in the lobby. Pass or cancel the running vote at any time.

🏷️ Server Name & Password

Both last until the server restarts. The password is sent straight to the server and never written to the bot's log or chat.

🚦 Join Limits & VPN

Max ping is only checked as players join; players already in stay. Off (or 0) lets everyone in, and the change lasts until the server restarts. VPN allowances apply on every server sharing the ban list. For a player who was refused as a VPN, use the ID from their "refused" line under Activity.
